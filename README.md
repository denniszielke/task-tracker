# Vehicle Pickup Orders Demo

A small React demo for viewing vehicles scheduled to be collected from their
owners and delivered to a repair shop for inspection.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Available commands

- `npm run dev` starts the development server.
- `npm run build` creates a production build in `dist/`.
- `npm run lint` checks the source with Oxlint.
- `npm run preview` serves the production build locally.

## Demo data

Pickup orders are stored in `src/data/orders.json`. Edit or add records there
to change the orders shown in the app.
